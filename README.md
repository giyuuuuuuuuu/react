# React

Proyecto Vite con React y TypeScript para el laboratorio practico 3.

Incluye:

- `DataTable<T>` generico con columnas tipadas por `keyof T`.
- Estado temporal de edicion basado en `Partial<T>`.
- Utilidad estricta de calculo de dias con `date-fns`.

## Comandos

```bash
npm install
npm run dev
npx tsc --noEmit
```
